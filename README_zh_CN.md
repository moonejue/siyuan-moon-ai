# 月照 AI 笔记助手

[English](https://github.com/moonejue/siyuan-moon-ai/blob/main/README.md)

月照 AI 是一个思源笔记写作助手。它可以同时引用多篇笔记，运行自定义快捷指令，并把 AI 回答复制、追加或替换到指定笔记。

![月照 AI 笔记助手预览](https://raw.githubusercontent.com/moonejue/siyuan-moon-ai/main/preview.png)

## 功能

- 在对话输入框中输入 `@`，实时检索并连续引用一篇或多篇笔记。
- 保存多套 AI 连接方案，每套独立保存供应商、地址、模型、API Key、温度和系统提示词。
- 支持 DeepSeek、OpenAI、Ollama、LM Studio 和自定义 OpenAI 兼容接口。
- 指定一篇笔记作为写回目标，将 AI 结果一键复制、追加到目标或替换目标正文。
- 新增、删除和修改快捷指令及提示词。
- 在笔记中选中文字后显示划词 AI 工具条，支持润色、翻译、总结、扩写、精简、改写、续写和觉知风格。
- 划词生成后对照原文与新文，并继续编辑、重新生成、复制、替换选中文字或插入原文后。

## 安装

上架后可在思源笔记的「集市 - 插件」中搜索「月照 AI 笔记助手」并安装。

手动安装时，从 GitHub 最新 Release 下载 `package.zip`，解压到 `<思源工作空间>/data/plugins/siyuan-moon-ai`，然后重启思源笔记。

## 使用方法

1. 启用插件后，点击思源顶栏的月亮图标，或在 macOS 使用快捷键 `Option + Command + M`，插件会在右侧栏中打开。
2. 在「AI 设置」中新增或选择连接方案，填写模型名和 API Key，然后测试连接。
3. 在「对话与修改」的输入框中输入 `@` 搜索笔记，或点击「引用当前笔记」。菱形标记的笔记是写回目标。
4. 输入需求后发送，或直接点击快捷指令。
5. 对 AI 回答使用「复制」「追加到目标」或「替换目标正文」。
6. 在任意笔记文本块内选中一段文字，在自动出现的工具条中选择 AI 修改方式，然后在对照窗口中应用或继续处理。

## 本地模型

- Ollama 默认地址为 `http://127.0.0.1:11434`，模型名需与 `ollama list` 显示的名称一致。
- LM Studio 默认地址为 `http://127.0.0.1:1234/v1`，需先在 LM Studio 中加载模型并启动本地服务。

## 隐私与数据说明

- AI 连接方案和 API Key 仅保存在当前思源工作空间的插件数据目录中。
- 使用远程 AI 时，当前指令和所选引用笔记的内容会发送给对应供应商，请根据供应商隐私政策谨慎使用敏感内容。
- 使用 Ollama 或 LM Studio 时可以在本机完成处理。
- 替换笔记正文前会再次确认，思源文档历史是误操作后的恢复方式。
- 插件在思源发布模式中禁用，避免公开发布页面使用或暴露本地 AI 配置。

## 兼容范围

- 思源笔记 `3.0.0` 或更高版本。
- 支持桌面端、桌面浏览器和桌面窗口前端。
- 支持 macOS、Windows、Linux 和 Docker 后端。
- 当前不支持移动端前端。
